# Employee Attrition Analysis

A beginner Python project exploring attrition patterns in synthetic employee data.

## Business question

How does employee attrition vary across departments, job roles, and length of service in this sample?

## Project contents

- `PROJECT_PLAN.md` — the business question, planned analysis, and scope
- `FINDINGS.md` — results and limitations
- `employee_attrition_analysis.py` — Python analysis and charts
- `data/employee_attrition.csv` — synthetic sample data
- `data/DATA_DICTIONARY.md` — descriptions of the dataset columns

## Run the analysis

With Python, Pandas, and Matplotlib installed, run this from the project folder:

```bash
python employee_attrition_analysis.py
